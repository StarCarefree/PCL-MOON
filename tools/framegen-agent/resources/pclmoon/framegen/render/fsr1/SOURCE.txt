easu.frag, rcas.frag, fullscreen.vert and linear.frag are local GL 3.3 wrappers.
They include the official headers unmodified. EASU gather4 is emulated with texelFetch
because textureGather is not in the GL 3.3 core profile. linear.frag is a reference
bilinear blit and is not part of FSR.

For strict GLSL 3.30 compilers, the local include preprocessor changes unsigned
constant zero initializers in the generated shader text from 0 to 0u. The
vendored upstream headers themselves remain byte-for-byte unchanged.
